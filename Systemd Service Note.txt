Notes on Systemd service:
Video: https://www.youtube.com/watch?v=-aKb-k8B8xo 

Change teststream to file name
Go here in terminal: /etc/systemd/system
sudo nano rtspstream.service
Do the correct format
Save, exit, check status:
systemctl status rtspstream.service
Enable: 
sudo systemctl enable rtspstream.service

Can run with:
sudo systemctl start rtspstream.service

Stop and disable:
sudo systemctl stop rtspstream.service
sudo systemctl disable rtspstream.service
